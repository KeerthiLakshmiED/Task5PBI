# 🏥 Hospital Dashboard

## 📌 Project Overview
The **Hospital Dashboard** is a data visualization project designed to analyze hospital admission data. It provides insights into patient demographics, admission types, insurance providers, yearly admission trends, and hospital-wise admissions through interactive charts and visualizations.

The dashboard helps users understand patient admission patterns and explore healthcare data efficiently.

## 🎯 Objectives
- Analyze the total number of patients and their average age.
- Understand admissions across different age groups.
- Compare hospital admissions.
- Identify trends in admissions over the years.
- Analyze admissions by type.
- Explore gender-wise admission trends.
- Provide interactive filters for better data exploration.

## 📊 Dashboard Features

### 1. Key Performance Indicators (KPIs)
- **Total Patients:** Displays the overall patient count.
- **Average Age:** Shows the average age of patients.

### 2. Admission Type Filter
Allows users to filter patient data by:
- Elective
- Emergency
- Urgent

### 3. Insurance Provider Filter
Provides filtering options based on insurance providers, including:
- Aetna
- Blue Cross
- Cigna
- Medicare
- UnitedHealthcare

### 4. Total Admission by Age Group
A pie chart representing patient admissions across different age groups:
- Middle Adult
- Pediatric
- Senior
- Young Adult

### 5. Total Admission by Hospital
A bar chart comparing the number of admissions across different hospitals.

### 6. Total Admission by Year
A line chart showing yearly admission trends from 2019 to 2024.

### 7. Total Admission by Admission Type
A pie chart visualizing the distribution of admissions by type:
- Elective
- Urgent
- Emergency

### 8. Gender-Wise Admissions by Year
A chart comparing female and male admissions across different years.

### 9. Patient Data Summary
A tabular view presenting patient admission information across age groups and medical conditions, including:
- Arthritis
- Asthma
- Cancer
- Diabetes
- Hypertension
- Obesity

## 📈 Key Insights
- The dashboard provides an overview of total patients and average patient age.
- Age-group analysis helps identify admission distribution across different demographics.
- Hospital-wise analysis enables comparisons of patient admissions.
- Yearly trends help users explore changes in admissions over time.
- Admission-type analysis highlights the distribution of elective, emergency, and urgent admissions.
- Gender-wise analysis helps compare admission patterns between male and female patients.
